Gestion des lots

Atelier de l'organisateur

Génère ou importe jusqu’à trois codes par lot. Chaque adresse validée est envoyée à postmaster@lotaku.fr et reste consultable dans ce panneau en cas d’échec de l’envoi. Le jeton administrateur n'est pas enregistré par le navigateur.

Seul le serveur Cloudflare vérifie ce secret. Ne l'envoie jamais à un gagnant et ne le mets jamais dans GitHub.

🎟️ Nouveau code gagnant

Trois codes en attente au maximum par lot. Chaque code ne peut servir qu’une seule fois.

Importer les neuf codes privés

Colle les lignes « lot;code » du fichier privé remis séparément. Rien n’est enregistré dans GitHub ou dans le navigateur.

Conserve le code généré : il est affiché une seule fois, et seul son condensat est enregistré en base.

📦 Livraisons Printful

Consulte les adresses reçues, copie les coordonnées de livraison et marque les colis expédiés. La commande Printful doit être effectuée séparément.

⚠️ Aucun envoi n'est automatisé vers Printful. Avant toute commande, vérifie les tailles, la destination et les frais d'expédition dans Printful.
